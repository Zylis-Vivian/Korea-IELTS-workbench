把韩语教材 PDF 放到这个目录（public/books/korean/）。

命名建议（与教材中心数据 books.ts 的 id 对应）：
  std-korean-1.pdf, yonsei-1.pdf ... yonsei-6.pdf,
  sejong-1.pdf, vitamin-1.pdf, grammar-live-basic.pdf ...

配套音频 MP3 放到：public/audio/korean/<教材id>/
  例如 public/audio/korean/yonsei-1/lesson-01.mp3

放入后刷新工作台，即可在「教材中心 → 书架」点击阅读 / 播放。
